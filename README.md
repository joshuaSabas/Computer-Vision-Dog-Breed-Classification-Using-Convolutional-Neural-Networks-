# Dog Breed Classifier

A Flutter app for dog breed classification using a TensorFlow Lite model.

## Setup

1. Install Flutter.
2. Run:

```bash
flutter pub get
flutter run
```

## Important

- Add your TensorFlow Lite model file in `assets/models/model_unquant.tflite`.
- If you have a labels file, place it in the same folder and update the code accordingly.
- The sample app is already set up to load the model asset.
